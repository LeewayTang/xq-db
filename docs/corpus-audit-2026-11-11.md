# 语料质量抽样审计（2026-11-11）

## 范围与方法

- 语料：15,712 部版本，其中 A 级 13,208、B 级 2,483、C 级 1、Q 级 1。
- 方法：从 A 级中随机抽取 400 部规范化文本，计算四项指标：
  - 唯一字符比例（unique ratio）
  - 行重复率（line repeat）
  - 短行比例（<6 字）
  - 正文字符数
- 对指标最差的样本做人工阅读复核。

## 指标分布

| 指标 | p05 | p50 | p95 |
|---|---|---|---|
| 唯一字符比例 | 0.012 | 0.082 | 0.356 |
| 行重复率 | 0.000 | 0.024 | 0.268 |
| 短行比例 | 0.000 | 0.095 | 0.474 |

文言文的唯一字符比例天然偏低：大规模史书（如《资治通鉴注》578 万字）唯一字比例约 0.001，属于正常现象，不能据此判为低质量。

## 结论

1. 抽样未发现“只有目录、没有正文”或“编码损坏”的批量混入。
2. 规则审核偏保守，但对这个以人工整理为主的语料库是合适的；C/Q 数量少不代表漏检严重。
3. 真正需要改进的是**章节切分**：大量殆知阁文本没有 `◇` 标记，整书成为一个章节，影响检索排序与标注切块。后续应按 `卷一 / 第一 / 篇名` 等结构做通用分章，再重新规范化。
4. LLM Reviewer 上线后，建议对 B 级与所有新入库批次做抽样复核，而不是全量重判。

## 复现

审计脚本未入库；指标可用规范化 Markdown 与 `edition.path` 直接重算。
